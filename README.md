# Combat Indicator — Issue Tracker

This repository is used only for tracking bugs and feature requests for
**Combat Indicator**, a Minecraft Fabric mod. It does not contain the mod's
source code.

- 📦 Download the mod on [Modrinth](https://modrinth.com/mod/combatindicator)
- 🐞 Found a bug or have a suggestion? [Open an issue](../../issues/new/choose)

When reporting a bug, please include:
- Minecraft version
- Fabric Loader / Combat Indicator version
- Steps to reproduce
- Screenshots or logs, if relevant
